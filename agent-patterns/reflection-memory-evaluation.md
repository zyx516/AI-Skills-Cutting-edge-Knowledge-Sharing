# 反思、记忆与评测

## 反思：从失败中得到下一步

**反思（Reflection）**是把上一次尝试得到的反馈转化为下一次尝试的简明经验。它不应等同于让模型无限地“再试一次”。

有效反思会记录：哪里失败、可能原因、支持这一判断的证据，以及下一步准备做出的具体改变。

## 记忆：保存真正有用的信息

**记忆（Memory）**只保存能改善未来决策的信息：任务约束、已验证事实、工具结果、关键决策和失败经验。

好的记忆应是有选择的、范围受控的，并且可刷新；过期或未经验证的记录会让 Agent 自信地犯错。

## 评测：让循环真正闭合

**评测（Evaluation）**让循环真正闭合。在部署前，要定义具有代表性的任务和成功标准；运行中要收集失败案例、检查原因，并更新提示词、工具、策略或测试。

应同时衡量质量、成本、延迟和安全性，而不是只看输出是否“听起来合理”。
